# Number Together 画面の資料(Claude Code用)

このフォルダには、**採用した画面だけ**が入っています。迷っていた案や、試して外した案(足元のリング、ふちの飾りなど)は入っていません。

- `screens/` … 画面の見本(単体で開けるHTML)。見た目、配置、文言、動きを、そのまま写してください
- この`README.md` … 画面ごとの、出す場面・内容・動き・注意
- ルールや、データの持ち方は、別の資料(`initial-requirements.md`)にあります。この資料は、**画面だけ**です

## 見本の使い方

- 見本は、固定の見た目だけで、ボタンを押しても何も起きません。数字や名前は、すべて**見本の値**です
- 幅390×高さ844のスマホ縦画面が基準です。PCで開いたときは、中央に、同じ幅で出してください
- 書体は、Google Fontsの `Dela Gothic One`(大きな数字・見出し)と `M PLUS Rounded 1c`(本文)です。見本を開くとき、インターネットにつながっている必要があります
- 見本の動き(跳ねる、点滅、降りてくる、など)は、CSSのアニメーションで作ってあります。そのまま使えます
- 端末の「動きを減らす」設定(`prefers-reduced-motion`)のときは、動きをやめて、静止した表示にします。見本のCSSに、その分の書き方も入っています

## 言語(日本語・英語)

- ゲームの画面は、**日本語と英語**に対応します。画面の切り替えボタンで、切り替えます
- **この見本は、日本語版です**。英語版の見本は、`claude-code-screens-en/` にあります。英語の文言は、見本の日本語をもとに、Claude Codeが、短く、やさしい英語で作ってください
- 切り替えボタンは、見本の**右上**に入れてあります(動作はしません)。どの画面でも、同じ場所に置きます。ボタンには、切り替えた先の言語名を出します(今が日本語なら「English」、今が英語なら「日本語」)。上の余白に収まる小ささにして、グラフや小人を隠さないようにします
- すべての文言(見出し、ボタン、札、吹き出し、演出の文字、称号、AIの名前、注意書き)を、言語ごとの文言の一覧に分けて書き、画面の部品に直接書かないでください
- 英語は、日本語より長くなることが多いので、札・ボタン・吹き出し・カードの枠から、文字がはみ出さないようにします
- 他のプレイヤーが付けた名前は、翻訳せず、そのまま出します

## 部品

- **小人(参加者のキャラクター)**: 丸い頭と、丸みのある体。髪型・服の色・小物(帽子、めがね、リボン、ヘッドホンなど)の組み合わせで、一人ひとりを見分ける。基本のSVGは、`screens/13-achievement-card.html` や `screens/05-play.html` の中にある。1人分のSVGは、幅22×高さ32の座標(`viewBox="0 0 22 32"`)
- **AIのロボット**: 灰青色の四角い体で、頭にアンテナ、胸にランプ。ランプの色で性格が分かる(がめつい=赤、気まぐれ=青、調整役=緑)。座標は幅28×高さ40
- **トゲトゲの吹き出し・見出し**: 多角形(`polygon`)で作った、ギザギザの形。白または赤で塗り、黒い枠と影を付ける。**しっぽは付けない**
- **札(チップ)**: 角が丸い、小さな札。範囲内=緑、ぴったり=金、など。文字は黒
- **スコア・時間の数字**: `Dela Gothic One`

## 画面の流れ

```
初回だけ: 01 名前とキャラクター選び
        ↓
   ┌→ 02 集合中(人が少ないと 03 AIが加わる)
   │     ↓ 時間になったら
   │   04 3・2・1・スタート!
   │     ↓
   │   05 プレイ中  ←(途中参加の称号の帯は 06)
   │     ├ 最後の1分に入った瞬間: 07 ×3 タイム スタート!
   │     ├ 残り10秒:             08 終了10秒前
   │     ↓ 時間切れ
   │   09 終了!
   │     ↓
   │   10/11/12 結果発表(ぴったり / 成功 / 失敗)
   └─────┘ 次の回の集合へ

いつでも: 13 小人をタップ → 実績カード / 18 自分の画面
途中で来たとき: 14 満員 または 15 終了間際 → 待って、次の回の集合へ
通信が切れたとき: 16 つなぎ直す
つながりにくいとき: 17 混雑中
```

進行は、時計だけで決まります。1周は、集合30秒、ゲーム5分、結果発表30秒が仮置きです(設定で変える)。

## 画面ごとの仕様

### 01 名前とキャラクター選び(`01-setup.html`)

- **出す場面**: 初めて来たときの1回だけ
- **内容**: 見出し「はじめまして!」。選んだ小人が上で弾んでいる。名前の入力欄(全角6文字・半角12文字まで。「6 / 12」のように、数えた量を表示する。数え方は、全角を2、半角を1にして、合計12まで)。かみがた(5種類)、ふくの色(8色)、こもの(なし・めがね・ぼうし・リボン・ヘッドホン)の選択。ボタンは「おまかせ」(ランダム)と「これできまり!」
- **注意書き**: 「ブラウザのデータを消したり、ほかの端末で開いたりすると、べつの人として扱われて、実績は引き継がれません。」
- **選択中の表示**: ピンクの枠と、薄いピンクの背景
- **決める必要があること**: 髪型・小物の種類は、仮に5種類と4種類(増やすかは未定)

### 02 集合中(`02-lobby.html`)

- **出す場面**: 次の回が始まるまでの、約30秒
- **内容**:
  - 上のカード: 「つぎの開始まで あと22秒」の大きなカウントダウン、残り時間を示すバー、「集合中」の札
  - 「あつまった人」: 「12 / 20人」。参加者を4列で並べる。小人の下に、名前と称号の札。小人は、ゆっくり上下に揺れる。空いている席は、点線の枠で「空き」
  - 自分の枠: ピンクの縁と、薄いピンクの背景(「あなた」の文字は付けない)
  - 称号の札: 「ぴったり王」(金)、「常連」(灰色)、「欲張り」(ピンク)、「新人」(白の点線)
  - 「いまの目標 2,400」「12人 × 200」「成功は 2,160 〜 2,640」「人が増えると、目標も上がる」
  - 一番下に「+1と−1で、みんなで目標にぴったり合わせよう」
- **動き**: カウントダウンが減る。人が入ると、小人が増える(目標も上がる)
- **注意**: 実績が分かるのは、この集合中。小人をタップして実績カード(13)を見られるようにするかは、未定

### 03 集合中(AIが加わる)(`03-lobby-ai.html`)

- **出す場面**: 人間が5人未満のとき(開始の直前)
- **内容**: 02と同じ作りで、人間2人 + AI3人。「人が少ないので、AIが3人 加わるよ」の黒い札。AIの席は、点線の枠で、ロボットの姿に、名前(がめついAI、気まぐれAI、調整役AI)と「AI」の札。「あと15席 あいています」。目標は「1,000」(5人 × 200)、「AIも人数に入るよ」
- **動き**: AIの小人が、点線の席の中に、ふわっとフェードインして現れる(順番に、0.5秒ずつずらす)。上から降りてくる演出は、ゲーム中の途中参加(05)だけで、ここでは使わない

### 04 3・2・1・スタート!(`04-start.html`)

- **出す場面**: 集合からゲームに変わる瞬間(約4秒)
- **内容**: 集合中の画面が暗くなり、大きな「3」「2」「1」が、1秒ずつ出て、最後に赤い「スタート!」が出る(白い文字に、黒い太い縁取り)
- **動き**: 数字が、大きく出て、縮みながら消える。「動きを減らす」のときは、「スタート!」だけを静止して出す

### 05 プレイ中(`05-play.html`)

最も大事な画面。上から順に:

1. **小人の舞台**(高さ88px): 参加者(AIも含む)の小人が1列に並ぶ。隣どうしは、体の約1/3ずつ重なる(奥と手前で、立つ位置を少しずらす)。いま押している人の小人が、跳ねる(高さ・速さは、押し方の強さに合わせる)。**+1か−1かは分からない**。自分の小人(絵では、ピンクのポニーテール)の頭の上に、ピンクの小さな吹き出しで「あなた」を、いつも出す(舞台の上にはみ出して出す。自分の小人は、いちばん手前)。自分が押したとき(絵では、0.6秒ごとに繰り返す)は、小人が跳ね、頭の横に小さな「+1」の吹き出しがふわっと浮かんで消える。**倍増タイム中も「+1」のまま**(「+3」にすると、目標の数字が3増えたように見えるため)。−1のときは「−1」を出す(仮)。他の人には出ない。右下に「20人が参加中」。人数が多いときは、名前は小人をタップしたときだけ出す
2. **「いまの数字」と大きな数字**(例: 3,987)。右に、緑の「範囲内!」の札(下端を数字に揃える。範囲の外のときは、色と文言が変わる)
3. **グラフ**:
   - 縦軸: 目標の±10%の範囲を緑の帯で出し、右に数字(例: 3600・4000・4400)。目標の線は点線
   - 横軸: 時間。右から1/3あたりを「いま」とし、点線と丸印で示す。線は「いま」までを描き、右側(未来)は線を引かない
   - 未来の部分: 最後の1分の「×3 ボーナス」を、斜線の帯と、赤い四角の「×3 / ボーナス」で示す。「終了」の線(「終」と「了」の札の間を、線が通る。札は背景が黒・文字が白)。終了の線より右は、薄く灰色
   - 左上に「残り 0:48」(残り時間はここに出す。画面の左上には出さない)
4. **あなたのポイント**(押すたびに、数字がぽんと弾む): 黒い表示板(白い見出し「あなたのポイント」、黄色の数字「152p」)。ボタンと似せないため、枠も影もない。自分のポイントだけが見える
5. **「いま押すと ×3!!」**: +1ボタンの上に、トゲトゲの吹き出し(しっぽなし)。倍増タイムを知らせる
6. **ボタン**: 「−1」(白)と「+1」(ピンク)は、同じ大きさで、左右対称に並ぶ

- **目標が上がったとき**(途中参加): 「目標UP! 3800 → 4000」のトゲトゲの吹き出しが出て、グラフの範囲の帯と目標線が、少し上に動く。同時に、入った人の小人が、画面の上から、光の柱の中を、キラキラをまとって、ゆっくり降りてきて、地平線に着く(着いたとき、少しつぶれる)。1周約7秒の動きとして作ってある
- **自分のポイント**: 自分が押したときは、通信を待たずに、すぐ反映する
- **決める必要があること**: 未来の長さ(約60秒分)は、仮の値

### 06 プレイ中(途中参加の称号の帯)(`06-play-late-join.html`)

- **出す場面**: 称号のある人が、途中から入ったとき
- **内容**: 05と同じ。加えて、画面の上に、黒い帯で「ぴったり王 さくらさん 参戦!」(金色の札 + 白い文字)。召喚の動きと同じタイミングで出る
- **注意**: プレイ中に実績を見ない、という考えとは合わないので、あとから消すかもしれない

### 07 ×3 タイム スタート!(`07-x3-start.html`)

- **出す場面**: 最後の1分(倍増タイム)に入った瞬間
- **内容**: プレイ画面が少し暗くなり、赤いトゲトゲの「×3 タイム!」が、脈打つ。下に「最後の1分は、ポイントが3倍!」の白い札。まわりに、きらめき
- **動き**: 脈動(拡大・縮小)と、きらめきの点滅

### 08 終了10秒前(`08-ten-seconds.html`)

- **出す場面**: 残りが10秒になったとき
- **内容**: プレイ画面のまま。**画面のふちが、赤く点滅する**。グラフの左上の残り時間が、「残り 0:10」と、赤い背景・白い文字・黒い枠と影で強調され、脈動する
- **しないこと**: 大きなカウントダウンの数字や、「もうすぐ終わる!」の札は出さない(グラフが隠れるため)

### 09 終了!(`09-end.html`)

- **出す場面**: 時間切れの瞬間
- **内容**: 画面が暗くなり、黒い帯が、左から斜めに入ってきて、白い「終了!」(金色の線で縁取り)。下に「判定しています」と、3つの点が動く
- **動き**: 帯が勢いよく入って、少し弾む

### 10・11・12 結果発表(`10-result-perfect.html`、`11-result-clear.html`、`12-result-fail.html`)

3つとも同じ並び。上から: 結果の見出し、最終の数字と範囲、あなたのポイント、みんなのポイントの一覧、次の回までのカウントダウン。

| | 10 ぴったり | 11 成功 | 12 失敗 |
| --- | --- | --- | --- |
| 見出し | 赤いトゲトゲに白い「ぴったり!」、きらめき(4つ) | 緑のトゲトゲに白い「成功!」、きらめき(2つ) | 飾りなしの黒い「残念…」 |
| 見出しの下の札 | 金「目標とぴったり同じ! ボーナス」 | 白「範囲の中でクリア!」 | 白「あと 120 足りなかった」 |
| 数字の例 | 4,000 | 4,130 | 3,480 |
| 範囲の札 | 金「ぴったり」 | 緑「範囲内」 | ピンク「範囲の外」(×の印) |
| ポイント | 「152p ボーナス ×2 = 304p」(赤い大きな数字) | 「152p もらえた!」 | 灰色の取り消し線「152p」と「もらえなかった」(見出しは「貯まっていたポイント」) |
| 累計 | 3,420 → 3,724 p | 3,420 → 3,572 p | 3,420 p(変わらず) |

- **みんなのポイント**: 上位7人と、自分の行(ピンクの枠)。自分が圏外のとき(11の例は14位)は、7位の下に「・・・」を出して、自分の行を下に出す。失敗のときも、貯まっていたポイントを載せる。AIも載せる
- **一番下**: 黒い帯に「つぎの回まで あと 24秒」とバー
- **仮の値**: ぴったりボーナスの「×2」は、仮の倍率

### 13 実績カード(`13-achievement-card.html`)

- **出す場面**: 小人をタップしたとき
- **内容**: 背景が暗くなり、中央にカード。大きな小人、名前(例: ゆうき)、称号の札(例: 常連)。参加・成功・ぴったり成功・累計ポイントの4つの数字。「ほかをタップすると閉じる」
- **注意**: 足元のリングなど、実績による小人の見た目の違いは付けない

### 14・15 待機(`14-wait-full.html`、`15-wait-last-minute.html`)

- **出す場面**:
  - 14: ゲーム中に来て、全部の部屋が満員のとき
  - 15: 終了の1分前以降に来たとき
- **内容**: 見出しだけが違う(14「いまは満員だよ」、15「もうすぐ終わるよ」+「終了の1分前からは、途中参加できません」)。黒いカードに「つぎの回まで 1:18」の大きなカウントダウンとバー、「時間になったら、そのまま参加できます」。下に「待っています」と、3つの点が動く
- **しないこと**: ゲームの様子は見せない。部屋の番号も出さない
- **実装のヒント**: 1つの画面にして、見出しの文言だけを切り替える作りにできる

### 16 通信が切れたとき(`16-offline.html`)

- **出す場面**: 通信が切れたとき
- **内容**: 見出し「つながらない…」。電波のマークに赤い斜線の絵(ゆらゆら揺れる)。「つなぎ直しています」と3つの点、「3回目のトライ中」。説明2つ(「つながったら、続きから参加できます」+2行目に「(終了の1分前まで)」、「1分以上つながらないと次の回から参加になります」)。ボタン「いますぐ、つなぎ直す」
- **仮のルール**: 「1分以上つながらないと次の回から」は、仮

### 17 混雑中(`17-busy.html`)

- **出す場面**: 無料プランの同時接続の上限に近づいて、入れないとき
- **内容**: 見出し「いま混み合ってるよ」。小人たちが、ぎゅうぎゅうに立って、跳ねる絵。「少し待ってから、もう一度ためしてね」。「自動でためします あと 10秒」のバー(10秒で減る)。ボタン「いますぐ、ためす」
- **仮の値**: 10秒は、見本の値

### 18 自分の画面(`18-me.html`)

- **出す場面**: いつでも(自分のボタンから開く)。右上の×で閉じる
- **内容**: 自分の小人(弾んでいる)、名前、称号の札、「名前・キャラをかえる」ボタン。「じぶんの実績」(参加・成功・ぴったり成功・累計ポイントの4つ)。「せってい」に「動きをへらす」のスイッチ。一番下に、実績が引き継がれない旨の注意書き
- **決める必要があること**: 「動きをへらす」のスイッチを、画面の中にも置くか(端末の設定に従うことは決まっている)
